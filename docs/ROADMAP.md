- [x] **渐进扣款**：按进度逐帧付费，缺钱即卡住；取消返还已付部分
- [x] **建造就绪 → 放置 → 施工**，AI 走同一流程

- [x] **防空规则**：只有 `antiAir` 武器能打飞机
- [x] **断电后果**：生产减速、炮塔迟滞、雷达离线、超级武器暂停
- [x] **补给箱**（晶体/维修/晋升）与**矿脉再生**
- [x] **程序化音效**（WebAudio 合成，零音频资源）
- [x] **AI 升级**：超武释放、工兵占领、扩张、按兵种搭配生产

## v0.5 等距地图与帧序列（当前）

这一版是对 `docs/REFERENCE-PARITY.md` 里四个方向性错误中 E2/E3/E4 的直接修正。
**改动不可逆**：世界从直角俯视换成等距投影，单位从「每帧矢量重绘」换成「8 方向帧序列」。

### 交付

| 项 | 说明 |
|---|---|
| 等距投影 | `world/Iso.ts`；模拟层保持直角坐标，只在渲染/拾取投影 |
| 整数高度层 | `Terrain.level`（0/1/2）+ `Terrain.vh` 顶点高度场 |
| 坡道 | 相邻格共享顶点高度，1 层高差自动成为一格宽斜坡（等价 `rampType`） |
| 等距地形 | 逐格菱形 + 抬升格补侧墙 + `(tx+ty)` 画家序 |
| 深度排序 | 建筑/单位合并到 `L2_World`，按投影 y 重排 sibling |
| 迷雾 | 按行合并的等距条带，三档硬边 |
| 帧序列 | `render/Frames.ts`：`Seq` / 帧数 / 帧率 / `Anim` 时钟 |
| 8 方向 | `facingIndex(deg)` 照抄原版公式；节点不再旋转 |
| 等距车体 | `isoBody()`：旋转长方体的侧壁 + 顶面 + 滚动履带 |
| 炮塔解耦 | `turretFace / turretAim / turretHold`，独立追踪后回正 |
| 转向前置 | > 49° 时本帧只转向不位移 |
| 等距框选 | 逐单位投影判屏幕矩形（修掉 AABB 漏选） |

## 技术债

1. 避障是"质量分离 + 对冲让位 + 卡住重规划"，不是完整 RVO；极窄走廊仍可能短暂推挤 → v0.5 引入简化 RVO。
2. 卡片与 HUD 命令式刷新，条目多时仍会全量重算 → 抽成轻量数据绑定。
3. 迷雾/小地图每帧重算 128×128 纹理，低端机可降到 10Hz；物理与弹道尚未做低端机降级。
4. 场景中 `Boot` 组件以压缩 UUID 挂在 `App` 节点，脚本改名/迁移目录会导致 UUID 变化 → 需在编辑器重新挂载。
5. 建筑队列只有 1 格，连续造墙/连续补建筑时操作偏多 → v0.4 支持队列 3 格与拖拽放置。
