## 技术债

1. 单位避障目前是分离力近似，复杂地形会挤压 → v0.2 引入局部避让（RVO 简化版）。
2. 卡片与 HUD 目前是命令式刷新，条目多时会有抖动 → v0.2 抽成轻量数据绑定。
3. AI 无侦查与克制决策 → v0.2 加"侦察单位探路 + 兵种配比"。
4. 场景中 `Boot` 组件以压缩 UUID 形式挂在 `App` 节点上，脚本改名/迁移文件夹会导致 UUID 变化 → 若改名，需在编辑器里重新挂载组件。
