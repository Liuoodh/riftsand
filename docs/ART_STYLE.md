# 视觉规范 · 裂沙战线

美术风格对齐项目初始参考图：**暖色沙海 + 深色金属 + 青色霓虹** 的 2.5D 俯视风格。
本项目没有外部贴图，全部图形由 `cc.Graphics` 在运行时绘制（`project/assets/scripts/render/Art.ts`），
好处是包体极小、风格统一、任意分辨率不糊；代价是需要严格遵守下面的绘制规则。

## 形状语言

- **阵营差异靠"轮廓 + 霓虹走向"，不靠配色区分**：
  - 磐岩联合：矩形、圆柱、厚重梯形；霓虹横向排布，直角多。
  - 沙蜥商团：三角、帐篷、斜面；霓虹斜向/放射，弧线多。
- 所有建筑都有：地面投影 → 混凝土基座 → 主体方块 → 顶面 → 功能件 → 霓虹条 → 四角指示灯 → 阵营色横标。
- 所有单位都有：椭圆投影 → 本体 → 高光面 → 阵营色描边 → 霓虹点。
- 单位朝 +X 方向绘制，运行时旋转节点实现朝向；步兵不旋转，仅左右镜像。

## 光影

- 统一"左上打光"：高光在左上，投影向右下偏移 `(+3, -4)`，透明度 20%～24%。
- 建筑高度用"底部挤出条"表达：主体下方附加 8～12px 的暗色带，不做真实投影计算。
- 霓虹发光用两层描边模拟：外层宽 4 倍、透明度 ~23%，内层实色细线。

## 动效

| 事件 | 表现 |
| --- | --- |
| 开火 | 枪口闪光（0.12s 扩张圆） |
| 命中 | 火花（0.22s，青色小圆） |
| 爆炸 | 双层橙色扩散 + 外环，建筑爆炸更大 |
| 建造完成 | 绿色椭圆扩散 |
| 单位出场 | 绿色椭圆扩散 |
| 选中 | 双层青色椭圆地环 |
| 受击 | 单位纵向轻微拉伸一帧 |
| 飞行单位 | 上下浮动正弦（±2px） |

## UI 规范

- 分辨率基准 1280×720 横屏，安全边距 14px。
- 面板：`#10141a` + 86% 不透明度，圆角 9～12px，1.2px 青色边框（`#1d7c8a`，60% 透明）。
- 强调线：面板上沿 2px 青色高亮条（30%～40% 透明）。
- 卡片：78×96，上方图标（缩放 0.55 世界美术），下方名称（12px）+ 造价（11px，琥珀色）。
- 按钮：高 30～44，圆角 6，激活态青色描边 + 上沿高亮。
- 文字：系统字体（`PingFang SC / Microsoft YaHei / sans-serif`），标题 54，小节 19，正文 13～15，说明 11～12。
- 数值用等宽感强的粗体，资源数字始终在左上角固定位置。
- 中文全部使用简体，术语统一：晶体 / 晶砂、采集车、卸货点、指挥核心、科技建筑。

## 可读性红线

1. 单位在 0.5× 缩放下仍要看得出"人/车/飞机"三类轮廓。
2. 敌我区分不依赖颜色单通道：敌方单位血条为红色、选中环为青色。
3. 任何面板不能遮挡战场中心 60% 区域。
4. 迷雾未探索区为纯黑，已探索区压暗 45%，保证信息层级清晰。
